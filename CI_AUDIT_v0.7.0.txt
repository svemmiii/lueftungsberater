-------------------

Gezielte lokal ausführbare Regressionstests
-------------------------------------------
Diese Arbeitsumgebung enthält Home Assistant selbst nicht, deshalb können die
HA-fixture-gebundenen Tests hier nicht 1:1 wie in GitHub CI laufen.

Direkt ausgeführt wurden:
- 72 Engine-/Nacht-/Localization-Tests: grün
- 23 Provider-/Warnregeltests ohne HA-Fixture: grün
- 5 Notification-Helper-Tests: grün

Damit wurden 100 HA-unabhängige/isolierbare Testfälle lokal ausgeführt.
Der vollständige Satz von 127 Tests bleibt für GitHub CI mit
pytest-homeassistant-custom-component 0.13.337 / Python 3.14 vorgesehen.

Besonders geprüfte v0.7.0-Fälle
------------------------------
- amtliche Fenster-/Lüftungs-Schließanweisung => Safety-Lock
- allgemeine Warnung ohne Lüftungsanweisung wird nicht selbst nach Severity bewertet
- DWD bleibt eigener Wetterwarnpfad
- echte Entwarnung vs. "noch keine Entwarnung"
- Nachtfenster mit konfigurierbarer Endzeit und über Mitternacht
- Temperatur-Hysterese merkt den Raumbedarf unabhängig vom Lüftungsmodus
- Remote-Räume bleiben read-only und erzeugen keine Remote-Entities
- Remote-Protokoll v2 mit v1-Lesekompatibilität
- Quellfreigabe + Empfängerauswahl für Remote-Räume
- neue Remote-Räume werden nicht automatisch ausgewählt
- sichtbare Remote-Nutzung pro Raum/Assistent

Hinweis
-------
Die Advisor-Entity verwendet weiterhin `_unrecorded_attributes = MATCH_ALL`.
Die umfangreichen Karten-/Diagnoseattribute bleiben damit aktuell verfügbar,
werden aber nicht als eigener Attributverlauf in den Recorder geschrieben.
