Lüftungsassistent v0.7.1 – Release Audit

Release-critical fixes verified in source:
- ConfigFlow MINOR_VERSION = 7, so the v0.7.1 remote-capability migration actually runs.
- Remote/Tailscale ConfigEntries expose no room subentry capability.
- Duplicate notification selector values removed.
- Official warning / all-clear notification state is assistant-level; ordinary airing transitions remain room-level.
- Assistant warning fingerprint is based on shared warning/weather data, not a room-specific result.
- Configurable night end is used by outside forecast relevance.
- Room coordinator schedules both night start and night end callbacks.
- Night display interval treats the configured end as exclusive.
- Remote export includes display_mode.
- CI no longer deletes accidental repository-root files before Hassfest/Pytest.
- Detailed card locks only the colored header area white.
- Detailed local room card shows an active remote-query icon.
- localized_texts is no longer stored on every advisor entity or remote snapshot.
- Per-user card language is rendered on demand through lueftungsberater/localize with English fallback.

Local validation in this environment:
- 131 unique test functions found; no duplicate test names.
- 73 engine/night/localization tests passed.
- 6 notification/helper tests passed.
- All Python files compile successfully.
- All JSON files parse successfully.
- GitHub workflow YAML parses successfully.
- Frontend JavaScript passes node --check.
- No release-critical root-layout cleanup is hidden in CI.

Limitation:
The complete pytest-homeassistant-custom-component suite cannot be executed in this container because the full Home Assistant test environment is not installed here. GitHub Actions remains the final Home Assistant integration/runtime validation.
