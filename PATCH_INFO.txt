v0.7.2 CI fix – stale MINOR_VERSION assertion

GitHub failure:
test_v071_config_flow_minor_version_republishes_remote_capabilities
assert 8 == 7

Cause:
v0.7.2 correctly advances ConfigFlow.MINOR_VERSION to 8 because it adds the
assistant-vs-room notification migration. The older v0.7.1 regression test
incorrectly required the current minor version to remain exactly 7 forever.

Fix:
The test now asserts MINOR_VERSION >= 7. This still guarantees that the v0.7.1
remote-capability migration is reachable, while allowing v0.7.2 and future
minor migrations.

Production code changed: none.
Replace: tests/test_config_flow.py
