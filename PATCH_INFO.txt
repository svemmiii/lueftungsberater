Lüftungsberater v0.6.24 - GitHub Actions / Repository-Struktur Fix
==================================================================

Ursache
-------
Beim bisherigen GitHub-Webupload sind mehrere Dateien, die eigentlich unter
custom_components/lueftungsberater/ bzw. tests/ liegen, zusätzlich im
Repository-Hauptordner gelandet.

Das verursacht zwei Probleme:
1. Hassfest findet das zusätzliche manifest.json im Root und meldet:
   [MANIFEST] Domain does not match dir name
2. Pytest findet Testdateien mit identischen Namen sowohl im Root als auch
   unter tests/. Das kann die Test-Collection mit Exit-Code 2 abbrechen.

Dieser Patch
------------
- lässt Hassfest das versehentlich im Root liegende manifest.json im
  Actions-Arbeitsverzeichnis entfernen;
- begrenzt Pytest ausdrücklich auf den korrekten tests/-Ordner;
- setzt testpaths = tests zusätzlich in pytest.ini;
- ändert KEINE Lüftungslogik und KEINE Dateien unter
  custom_components/lueftungsberater/.

Empfohlene einmalige Repo-Bereinigung
-------------------------------------
Die folgenden versehentlich im Repository-Root liegenden Duplikate sollten
bei Gelegenheit auf GitHub gelöscht werden. Die echten Dateien bleiben in
custom_components/lueftungsberater/ bzw. tests/ erhalten:

__init__.py

airing.py
config_flow.py

NICHT löschen:
- hacs.json
- pytest.ini
- README.md
- CHANGELOG.md
- LICENSE
- .github/
- custom_components/
- tests/
- reference/

Nach der Bereinigung bleiben die Änderungen an validate.yml und pytest.ini
sinnvoll und verhindern, dass versehentlich im Root abgelegte Testdateien
künftig wieder gesammelt werden.
